## 🌎 About the Project

EnviroCollective Regina is a community-focused climate action hub that connects people, organizations, businesses, and resources to support a more sustainable future.

This project focuses on remodelling the existing website to improve its usability, visual presentation, accessibility, content organization, and overall user experience.

**Existing website:** https://www.envirocollective.ca/

## 🎯 Project Goals

- 🎨 **Modern Design** - Create a clean, cohesive, and visually engaging interface.
- 🧭 **Better Navigation** - Make important information and resources easier to find.
- ♿ **Accessibility** - Improve readability, keyboard usability, and inclusive access.
- 📱 **Responsive Experience** - Design for mobile, tablet, and desktop screens.
- 🌱 **Clear Communication** - Present climate initiatives, community news, and resources effectively.
- ⚡ **Usability & Performance** - Improve the overall browsing experience.
